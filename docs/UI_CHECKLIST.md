# UI 확인 체크리스트 (카드 09 · 10 공용)

> 확인용 계정: `demo@demo.com` / `Test1234!` (`seed_mock_data.py` 시딩 후)
> 서버: `uvicorn app.main:app --reload` → http://127.0.0.1:8000

## 채팅 UX (#9)

- [ ] AI 답변이 여러 줄이면 줄바꿈 유지
- [ ] `**굵게**`·`` `코드` `` 마크다운이 렌더링됨
- [ ] `<script>` 입력해도 실행 안 됨 (XSS 차단 확인)
- [ ] 401이면 `/login` 이동 (로그아웃 후 전송 테스트)
- [ ] 502/504 에러 메시지가 말풍선으로 표시 (502는 오류를 반환하는 모의 AI, 504는 설정한 제한보다 긴 모의 응답 지연으로 각각 재현; AI 키를 제거하면 내부 데모 제공자가 선택됨)
